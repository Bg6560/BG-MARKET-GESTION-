## Règles de lecture

- **Confirmé** : la fonction existe dans le code publié et fonctionne. La plupart des fonctions confirmées sont couvertes par des tests automatiques.
- **Partiel** : la fonction existe avec des limites, qui sont précisées.
- **Non disponible** : la fonction n'existe pas, ou pas en service. Ne pas la présenter comme réelle.
- Toutes les captures utilisent des **données de démonstration**. Les noms comme « Client démo A », « Vendeur Démo » ou « Patron Démo » sont fictifs, tout comme les numéros 0100000001 et les montants. Les adresses e-mail ont été masquées automatiquement (« adresse masquée »).
- Rien dans ce dossier n'a modifié l'application.
